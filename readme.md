# 映画表現スタイルダッシュボード

## 概要

このダッシュボードは、「映画表現 - スタイル」グリモワールの内容を紹介するものです。写実系/非写実系の階層構造でスタイルを分類・表示し、各スタイルは東京の夜景を各スタイルで表現した画像と説明を含むカード形式で表示されます。

## 使用技術

- Next.js (App Router)
- shadcn/ui
- Tailwind CSS
- TypeScript

## 動作環境

- Node.js v20.0.0 以上
- npm v10.0.0 以上

## セットアップ

1. リポジトリをクローンします。
   ```bash
   git clone [リポジトリのURL]
   cd [リポジトリ名]
   ```

2. 依存関係をインストールします。
   ```bash
   npm install
   ```

3. 開発サーバーを起動します。
   ```bash
   npm run dev
   ```

4. ブラウザで `http://localhost:3000` にアクセスします。

## プロジェクト構成

```
project-root/
├── src/
│   ├── app/
│   ├── components/
│   │   ├── ui/
│   │   └── layout/
│   ├── hooks/
│   ├── lib/
│   │   ├── api/
│   │   └── utils/
│   └── styles/
├── public/
│   └── images/
├── structure.yaml
├── package.json
├── tsconfig.json
├── postcss.config.js
└── tailwind.config.js
```

- `src/app`: Next.js の App Router で使用されるページとレイアウトが含まれます。
- `src/components`: React コンポーネントが含まれます。
- `src/components/ui`: shadcn/ui で提供される UI コンポーネントが含まれます。
- `src/lib`: ユーティリティ関数とスタイル定義が含まれます。
- `public/images`: スタイルを表現する画像が含まれます。
- `structure.yaml`: プロジェクトの構造と依存関係を記述したファイルです。
- `package.json`: プロジェクトの依存関係とスクリプトを定義します。
- `tsconfig.json`: TypeScript のコンパイラオプションを定義します。
- `postcss.config.js`: PostCSS の設定を定義します。
- `tailwind.config.js`: Tailwind CSS の設定を定義します。
